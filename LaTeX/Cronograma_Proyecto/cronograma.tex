\section{Descripción del Proyecto}
El proyecto consiste en la simulación del confinamiento de plasma mediante un campo electromagnético utilizando Python. Se modelará el movimiento de partículas bajo la fuerza de Lorentz, integrando las ecuaciones diferenciales mediante el algoritmo de Boris o Runge-Kutta. El sistema incluirá colisiones aleatorias (modelo estocástico) y se empleará el método de Monte Carlo para calcular el tiempo de confinamiento promedio, analizando la pérdida de partículas en las paredes del contenedor. La visualización se realizará mediante animaciones con Matplotlib.
